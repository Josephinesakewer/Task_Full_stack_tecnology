XML → JSON

Конвертер и замер скорости в одном окне.

Вставьте любой корректный XML-документ и нажмите «Конвертировать».

Откройте эту страницу в каждом браузере, запустите замер и перенесите строки в общую таблицу (Excel).

Определено автоматически — при необходимости поправьте (например, Opera GX).

Методика

Измеряются три этапа: парсинг (DOMParser), обход дерева в объект JS (рекурсивная функция) и JSON.stringify. Перед замером выполняется 5 «прогревочных» запусков. Данные генерируются по фиксированному зерну, поэтому во всех браузерах это один и тот же XML — длина JSON в последнем столбце должна совпадать. Для честного сравнения закройте лишние вкладки и DevTools, подключите ноутбук к питанию и повторите замер в каждом браузере несколько раз. Точность таймера в Firefox и Safari может быть ограничена (около 1 мс и грубее), поэтому для малых данных ориентируйтесь на среднее по многим повторам.
